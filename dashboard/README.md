# Dashboard specification

## Executive view

**KPI cards:** Gross order value · Orders · Average order value · On-time delivery rate

**Trend:** Monthly revenue and order volume

**Commercial mix:** Revenue by product category and customer state

**Operations:** On-time vs late delivery and average review score

**Management questions:**
- Is revenue growth being driven by order volume or basket size?
- Which categories contribute the most value?
- Does delivery performance correspond with customer experience?

The dashboard is designed for Power BI and can be reproduced from the SQL outputs in `sql/` after loading the public Olist tables into PostgreSQL.
